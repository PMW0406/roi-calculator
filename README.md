# 원텍 ROI 계산기 (AppSheet 대체)

영업사원이 병원 현장에서 바로 사용할 수 있는 정적 웹 기반 ROI 계산기입니다.

## 구성

- RF/HIFU 탭: 투자금 회수기간 + 총 수익 계산
- Laser 탭: 투자금 회수기간 계산
- 모바일 우선 UI, 데스크톱 반응형 지원
- 사용자 수 제한 없음
- 불필요한 세부 항목 제거(월 매출/월 비용 중심)

RF/HIFU 사용 흐름:

- 장비명 선택
- 패키지명 선택
- 선택한 장비/패키지의 기본값 자동 세팅
- 1회 시술단가, 일 시술 횟수 입력 시 ROI 즉시 재계산
- 검증되지 않은 패키지는 `직접 입력` 선택 후 패키지 가격/소모품수/시술샷수/팁샷수를 수동 입력

## 로컬 실행

별도 설치 없이 [index.html](index.html) 파일을 브라우저로 열면 동작합니다.

4. Branch를 main /(root)로 선택 후 Save
5. 생성된 URL 접속

## 계산 로직 요약

RF/HIFU:

- 총 시술 횟수 = (팁/카트리지 샷수 / 시술샷수) x 제공 소모품수
- 총 매출 = 총 시술 횟수 x 1회 시술단가
- 순수익 = 총 매출 - 패키지 가격
- 원금회수일(일) = 패키지 가격 / (1회 시술단가 x 일 시술 횟수)

Laser:

- 패키지 가격 = 1회 시술단가 x 티케팅수
- 월 패키지 매출 = 패키지 가격 x 고객수
- 원금회수일(일) = (장비 가격 / 월 패키지 매출) x 30
